# HTML Learning

This repository serves as a learning reference for HTML. Instead of maintaining separate documentation, we use **[W3Schools HTML Tutorial](https://www.w3schools.com/html/)** as our primary learning resource.

W3Schools provides beginner-friendly tutorials, examples, and exercises covering HTML fundamentals.

## Learning Structure

```text
HTML
├── Introduction
├── Editors
├── Basic Examples
├── Elements & Attributes
├── Headings & Paragraphs
├── Formatting & Styles
├── Links & Images
├── Tables & Lists
├── Block & Inline Elements
├── Classes & IDs
├── Iframes
├── Forms & Input Types
├── HTML Graphics (Canvas & SVG)
├── HTML Media
├── Semantic HTML
└── HTML APIs
```
