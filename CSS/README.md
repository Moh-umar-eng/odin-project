# CSS Learning

This repository serves as a learning reference for CSS (Cascading Style Sheets). Instead of maintaining separate documentation, we use **[W3Schools CSS Tutorial](https://www.w3schools.com/css/)** as our primary learning resource.

W3Schools provides beginner-friendly tutorials, examples, and exercises covering CSS fundamentals.
